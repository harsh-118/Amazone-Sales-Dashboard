# Amazon Sales Dashboard

## Overview
The **Amazon Sales Dashboard** is a data visualization project designed to provide insights into sales performance. It displays key metrics such as total sales amount, courier status, top product categories, delivery partners, fulfillment methods, and shipping states.

## Dataset used
<a href="">Dataset</a>

## Features
- **Sales Amount:** Displays total sales in millions.
- **Courier Status:** Breakdown of shipped, on-the-way, cancelled, and unshipped orders.
- **Top Categories:** Highlights the most sold product categories.
- **Delivery Partners:** Shows the count of orders handled by different delivery partners.
- **Fulfillment Methods:** Compares Amazon vs. Merchant fulfillment.
- **Size Distribution:** Represents product sizes in sales.
- **Shipping States:** Identifies the top states where orders were shipped.
- **Dashboard Interaction:**<a href="https://github.com/harsh-118/Amazone-Sales-Dashboard/blob/main/Amazon%20sales%20report.pbix">Dashboard</a>

## Technologies Used
- **Power BI** for data visualization
- **Excel/CSV** for data storage
- **Python/Pandas** (optional) for data preprocessing

## How to Use
1. Open the Power BI file.
2. Load the dataset (Excel/CSV) containing Amazon sales data.
3. Refresh the dashboard to view updated insights.
4. Interact with the filters to analyze data across different time periods and regions.

## Future Improvements
- Integration with real-time sales data.
- Adding more advanced analytics and predictive insights.
- Customizable filters for enhanced user experience.
